How This Works
1 You enter the company name and click Authorize
2 Intuit's secure login page opens — you sign in with the QBO company's credentials
3 You grant permission — QBO redirects back with a secure authorization code
4 An isolated workspace is created with the company's Realm ID as the unique identifier
5 Run a Sync to load accounting data, then run an Assessment
Your QBO password is never entered into or stored by this application. Authorization uses OAuth 2.0. Tokens are encrypted before storage. Each company's data is fully isolated by Realm ID.
